# salary-calculator
シフト制・ルート手当対応のルート配達ドライバー向け給与計算ツール

## 概要
シフト制・ルート手当対応のドライバー向け給与計算ツールです。
毎月の深夜時間・残業時間・ルート手当を入力するだけで給与を自動計算します。

## 機能
- 基本給・各種固定手当の自動合算
- 深夜手当の自動計算
- 残業手当の自動計算
- ルート別手当の自動計算
- 給与記録のテキストファイル保存

## 使い方
1. `salary_public.py` を実行する
2. 深夜時間・残業時間を入力する
3. ルート名と日数を入力する（Enterだけで終了）
4. 給与計算結果が表示され、`給与記録.txt` に保存される

## カスタマイズ
以下を自分の環境に合わせて変更してください：
- 基本給・家族手当・無事故手当・通信費手当などの固定手当金額
- ルート名と手当金額
- 深夜手当・残業手当の単価

## 使用言語
- Python 3
